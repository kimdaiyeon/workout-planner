# 운동 플래너 DB 구축 문서

> 작성일: 2026-10-06 · 버전: v3 (바벨/머신 추가) · 소스: `site/workout-planner/index.html` 내 EX 배열
> 운동 114개 · 장비 10종 · 동작(부위×패턴) 21종 · 시연 영상 3개

## 1. 개요

단일 HTML 운동 플래너의 운동 데이터를 관계형 DB로 이전하기 위한 구축 문서.
현재 데이터는 JS 배열(`EX`)에 들어 있으며, 이 문서는 마스터 테이블·스키마·전체 데이터를 정리한다.

```
equipment (장비 마스터) 1──┐
movement (동작 마스터)  1──┼──< exercise_equipment >── exercise (운동)
                           └──< demo_video (시연 영상)
```

## 2. 테이블 스키마 (제안)

```sql
-- 장비 마스터
CREATE TABLE equipment (
  code  TEXT PRIMARY KEY,  -- body, db, kb, band, bar, cable, smith, legpress, bb, machine
  name  TEXT NOT NULL,      -- 맨몸, 덤벨, ...
  place TEXT NOT NULL,      -- 'home', 'gym', 'home,gym' (장비 선택 UI 노출 위치)
  unit  TEXT,               -- 세트/개/대/자리
  hint  TEXT                -- UI 안내 문구
);

-- 동작 마스터 (부위 × 패턴)
CREATE TABLE movement (
  part     TEXT NOT NULL,   -- back, chest, legs, shoulder, any
  pattern  TEXT NOT NULL,   -- press, squat, ...
  name_ko  TEXT NOT NULL,   -- 동작 한글명
  PRIMARY KEY (part, pattern)
);

-- 운동
CREATE TABLE exercise (
  id        INTEGER PRIMARY KEY,
  name      TEXT UNIQUE NOT NULL,
  part      TEXT NOT NULL,
  pattern   TEXT NOT NULL,
  is_gym    BOOLEAN DEFAULT FALSE,  -- 헬스장 전용 여부
  priority  INTEGER,                -- pri 1~4 (루틴 편성 우선순위)
  sets      INTEGER,
  reps      TEXT,                   -- '8~12', '30~45초', '한쪽 10' 등
  steps     JSON NOT NULL,          -- 수행 순서 배열
  mistakes  JSON NOT NULL,          -- 주의점 배열
  FOREIGN KEY (part, pattern) REFERENCES movement(part, pattern)
);

-- 운동-장비 매핑 (다대다: equip 배열이 2개 이상인 운동 존재)
CREATE TABLE exercise_equipment (
  exercise_id    INTEGER NOT NULL REFERENCES exercise(id),
  equipment_code TEXT NOT NULL REFERENCES equipment(code),
  PRIMARY KEY (exercise_id, equipment_code)
);

-- 시연 영상
CREATE TABLE demo_video (
  id            INTEGER PRIMARY KEY,
  exercise_name TEXT UNIQUE NOT NULL REFERENCES exercise(name),
  file_path     TEXT NOT NULL,
  duration_sec  REAL,
  width         INTEGER,
  height        INTEGER
);
```

## 3. 장비 마스터 (10종)

| code | 장비명 | 노출 위치 | 단위 | 안내 |
|---|---|---|---|---|
| `db` | 덤벨 | home,gym | 세트 | 양손 1쌍 = 1자리 |
| `kb` | 케틀벨 | home | 개 | 1개 = 1자리 |
| `band` | 밴드 | home | 개 | 1개 = 1자리 |
| `bar` | 풀업바 | home | 개 | 1개 = 1자리 |
| `cable` | 케이블머신 | gym | 대 | 1대 = 왼쪽·오른쪽 케이블 + 중앙 바, 3자리 |
| `db` | 덤벨 · 벤치 | home,gym | 자리 | 덤벨과 벤치를 동시에 쓸 수 있는 자리 수 |
| `smith` | 스미스머신 | gym | 대 | 1대 = 1자리 |
| `legpress` | 레그프레스 | gym | 대 | 1대 = 1자리 |
| `bb` | 바벨 | gym | 대 | 바벨 + 랙/벤치, 1대 = 1자리 |
| `machine` | 머신 | gym | 대 | 1대 = 1자리 |

> 참고: `bar`는 풀업바(철봉)이며 바벨이 아님. 바벨은 `bb`. 케이블머신 1대는 왼쪽·오른쪽 케이블 + 중앙 바(풀업바) 3자리를 제공.

## 6. 운동 상세

### 1. 덤벨 숄더 프레스

- 부위/패턴: `shoulder` / `press` (숄더 프레스)
- 장비: `db` 덤벨
- 헬스장 전용: 아니오 · 우선순위: 3 · 3세트 × 8~12
- 수행 순서:
  1. 앉거나 서서 덤벨을 귀 옆, 팔꿈치는 몸 약간 앞쪽에 둡니다.
  2. 숨을 내쉬며 머리 위로 밀어 올리고, 정점에서 팔꿈치를 완전히 잠그지 않습니다.
  3. 3초 정도로 천천히 내려 시작 위치까지 옵니다.
- 주의점:
  - 허리를 뒤로 꺾어서 미는 것 — 코어에 힘을 주고 갈비뼈를 내립니다.
  - 팔꿈치가 옆으로 완전히 벌어지는 것 — 약 30도 앞을 향하게.

### 2. 케틀벨 프레스

  3. 천천히 랙 위치로 내리고 반대쪽도 같은 횟수.
- 주의점:
  - 손목이 꺾여서 케틀벨이 뒤로 젖혀지는 것 — 손목은 항상 곧게.
  - 몸통이 옆으로 기울어지는 것 — 반대쪽 발에도 체중을 균등히.
