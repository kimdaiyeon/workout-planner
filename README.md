# workout-planner — 운동 자세 피드백 앱 서버

기준 운동 영상과 사용자 영상을 비교해 세트 사이 쉬는 시간에 자세 피드백을 주는 앱의 **서버(백엔드) 레포**.
기획·검토 내용은 [docs/form-feedback-app.md](docs/form-feedback-app.md), 작업 컨텍스트는 [CLAUDE.md](CLAUDE.md).

## 구성 (예정)

| 영역 | 상태 | 내용 |
| --- | --- | --- |
| 운동 추천 | 프로토타입 (`index.html`) | 부위·시간·기구·인원 → 운동 3~7개. 그룹이면 기구 자리별 사이클 배정 |
| 자세 분석 | 미착수 (Phase 1) | 세트 영상 → 포즈 추출 → 반복 분리 → 지표 → 기준 이탈 판정 → 피드백 문장 |
| 운동 메타데이터 | 일부 (`EX` 101개) | 하는 법·실수 문구는 있음. 촬영 각도·지표·허용 범위는 없음 |

## 플래너 프로토타입 (`index.html`)

빌드 없음. 브라우저로 열면 동작. 설정은 localStorage에 저장.

- 요일 기반 부위 자동 선택 (월 등 · 화 가슴 · 수 하체 · 목 어깨, 금~일 자유), 수동 변경 가능
- 장소(집/헬스장)별 기구 **개수** 입력. 케이블머신 1대 = 왼쪽 케이블 + 중앙 바 + 오른쪽 케이블 (3자리)
- 인원 1명: 패턴별 1종목씩, 세트 방식
- 인원 2명 이상: 자리(slot)마다 운동 배정 → 사이클 방식. 자리당 최대 2명 교대, 초과 시 맨몸 자리 추가
- 시간 20 / 30~40 / 60분 → 종목 수·세트·사이클 수 결정
- 운동 카드: 하는 법 / 흔한 실수 / 관절 인형 동작 시연(SVG) / 같은 자리 내 운동 교체

### 내부 구조

| 블록 | 줄 | 내용 |
| --- | --- | --- |
| `EQUIP` | 152 | 장소별 기구 정의. 각 기구가 만드는 slot(eq 종류 + 라벨) |
| `PARTS` | 168 | 부위별 움직임 패턴 5개 + 웜업 문구 |
| `TIME` | 181 | 시간별 종목/세트/사이클 수 |
| `EX` | 183 | 운동 DB 101개. `part`, `pattern`, `equip[]`, `pri`, `gym`, `steps[]`, `mistakes[]` |
| `RIG` / `sidePoints` / `frontPoints` | 505 | 관절 인형 FK. 각도 → 좌표 |
| `A` | 543 | 동작 유형 42개의 키프레임(A→B) + 소품 |
| `archetypeFor` | 593 | 운동 이름 → 동작 유형 매핑 (키워드 기반) |
| `drawFigure` / `playDemo` | 649 | SVG 그리기, 루프 재생 |
| `buildSolo` / `buildGroup` / `minutes` | 740 | 루틴 생성과 시간 추정. group은 slot × cycle 격자를 채움 |

### 인형 각도 규약 (측면 뷰, 인물은 +x 방향을 봄)
- `t` 몸통: 수직 0, 앞으로 숙이면 +
- `th` 허벅지 / `sh` 정강이: 아래 수직 0, 무릎이 앞으로 가면 +
- `ua` 위팔 / `fa` 아래팔: 아래 0, 앞 +, 머리 위 180, 뒤 −
- 루트는 `ankle` (서 있는 동작) 또는 `hip` (눕는 동작)

정면 뷰: `ab` 팔 벌림(0 아래, 90 T, 180 머리 위), `el` 팔꿈치 굽힘, `la` 다리 벌림, `kn` 무릎 굽힘
