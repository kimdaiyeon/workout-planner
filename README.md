# 4분할 운동 플래너

집/회사 헬스장에서 어깨·등·가슴·하체 4분할 루틴을 짜주는 단일 파일 웹앱.
빌드 없음. `index.html`을 브라우저로 열면 동작.

## 기능
- 요일 기반 부위 자동 선택 (월 등 · 화 가슴 · 수 하체 · 목 어깨, 금~일 자유), 수동 변경 가능
- 장소(집/헬스장)별 기구 **개수** 입력. 케이블머신 1대 = 왼쪽 케이블 + 중앙 바 + 오른쪽 케이블 (3자리)
- 인원 1명: 패턴별 1종목씩, 세트 방식
- 인원 2명 이상: 자리(slot)마다 운동 배정 → 사이클 방식. 자리당 최대 2명 교대, 초과 시 맨몸 자리 추가
- 시간 20 / 30~40 / 60분 → 종목 수·세트·사이클 수 결정
- 운동 카드: 하는 법 / 흔한 실수 / 관절 인형 동작 시연(SVG 애니메이션) / 같은 자리 내 운동 교체
- 설정은 localStorage에 저장

## 구조 (index.html 내부)
| 블록 | 내용 |
| --- | --- |
| `EQUIP` | 장소별 기구 정의. 각 기구가 만드는 slot(eq 종류 + 라벨) |
| `PARTS` | 부위별 움직임 패턴 5개 + 웜업 문구 |
| `TIME` | 시간별 종목/세트/사이클 수 |
| `EX` | 운동 DB 101개. `part`, `pattern`, `equip[]`, `pri`, `gym`, `steps[]`, `mistakes[]` |
| `buildSolo` / `buildGroup` | 루틴 생성. group은 slot × cycle 격자를 채움 |
| `RIG` / `sidePoints` / `frontPoints` | 관절 인형 FK. 각도 → 좌표 |
| `A` | 동작 유형 42개의 키프레임(A→B) + 소품 |
| `archetypeFor` | 운동 이름 → 동작 유형 매핑 (키워드 기반) |
| `drawFigure` / `playDemo` | SVG 그리기, 루프 재생 |

## 각도 규약 (측면 뷰, 인물은 +x 방향을 봄)
- `t` 몸통: 수직 0, 앞으로 숙이면 +
- `th` 허벅지 / `sh` 정강이: 아래 수직 0, 무릎이 앞으로 가면 +
- `ua` 위팔 / `fa` 아래팔: 아래 0, 앞 +, 머리 위 180, 뒤 −
- 루트는 `ankle` (서 있는 동작) 또는 `hip` (눕는 동작)
정면 뷰: `ab` 팔 벌림(0 아래, 90 T, 180 머리 위), `el` 팔꿈치 굽힘, `la` 다리 벌림, `kn` 무릎 굽힘
